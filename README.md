Entry for the make.fun bounty [Make the AI judge feel held](https://make.fun/c/make-the-ai-judge-feel-held-20261122-1600): a program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (200 characters). No network, deterministic — every run writes the same bytes.
